This repository contains the workflow to create a working pipeline to crosscompile for RISC-V from X86 eventually enabling RVV extension.

# ONNX-MLIR → RISC-V / RVV Workflow Guide

## Overview

This project contains a collection of scripts used to build and test an ONNX-MLIR workflow targeting RISC-V systems, including support for the RISC-V Vector Extension (RVV).

The scripts are designed to be executed in sequence because each stage depends on artifacts produced by the previous one.

For the full instructions on how to build LLVM and ONNX-MLIR visit https://github.com/onnx/onnx-mlir/tree/main

The various paths in each file are the ones I used, adapt them to your local paths.

The overall workflow is:

```text
LLVM + MLIR
      ↓
ONNX-MLIR
      ↓
ONNX Model Compilation
      ↓
RISC-V / RVV Shared Library
      ↓
Inference Executable
```

---

# Repository Scripts

This repository contains three main scripts:

| Script | Purpose |
|---|---|
| `build_llvm.sh` | Builds LLVM + MLIR with RISC-V support |
| `build_onnx_mlir.sh` | Builds ONNX-MLIR using the custom LLVM toolchain |
| `build_mnist_riscv.sh` | Compiles an ONNX model into a RISC-V shared library and executable |
| `build_mnist_riscv_rvv.sh` | Compiles an ONNX model into a RISC-V/RVV shared library and executable |

---

# 1. build_llvm_mlir.sh

## When to Use It

This script builds the infrastructure required by ONNX-MLIR.

---

## What It Produces

The script generates:

- LLVM compiler tools
- MLIR infrastructure
- Clang
- OpenMP runtime
- RISC-V backend support

The resulting build directory is later used by ONNX-MLIR.

---

## Dependencies

This script only depends on:

- Git
- CMake
- Ninja
- A C++ compiler

---

## Usage

```bash
./build_llvm.sh
```

---

# 2. build_onnx_mlir.sh

## When to Use It

Before running this script it is necessary to create and run a Python virtual environment.

This script builds ONNX-MLIR using the LLVM/MLIR toolchain produced by `build_llvm.sh`.

---

## Important Relationship

This script depends on the LLVM build generated by:

```text
build_llvm_mlir.sh
```

---

## Usage

```bash
./build_onnx_mlir.sh
```

---

# 4. Download source folder not included in latest release

The mnist model makes use of Tensors but the libraries are not included in the latest ONNX-MLIR release for some reason. To make it work download the folder at the following link: https://github.com/onnx/onnx-mlir/tree/main/src. It has to be put in the onnx-folder as it is on GitHub.

# 5. build_riscv_rvv_mnist.sh

## When to Use It

This script performs model compilation.

It converts an ONNX model into:

- RISC-V object files
- A shared library
- A runnable inference executable

---

## What It Produces

The script generates:

| File | Description |
|---|---|
| `*.onnx.mlir` | Intermediate MLIR representation |
| `*.ll` | LLVM IR |
| `*.s` | RISC-V assembly |
| `*.o` | Object files |
| `*.so` | Shared inference library |
| executable | Runnable inference application |

build_riscv_mnist.sh produces the same libraries and executable but not vectorized. If the plan is to execute both scripts create 2 different folders otherwise the outputs get mixed.

---

## RVV Support

This script enables:

```text
RISC-V Vector Extension (RVV)
```

using:

```bash
-mattr=+v
```

and:

```bash
-march=rv64gcv
```

This allows vectorized tensor operations.

---

## Important Relationship

This script depends on artifacts produced by:

```text
build_onnx_mlir.sh
```

Specifically:

- `onnx-mlir`
- Runtime headers
- Runtime support libraries
- MLIR lowering infrastructure

must already exist.

---

## Typical Usage

```bash
./build_riscv_rvv_mnist.sh
```

# Pipeline Overview

| Component | Role |
|---|---|
| LLVM | Backend compiler infrastructure |
| MLIR | Intermediate representation framework |
| ONNX-MLIR | ONNX compiler |
| GCC RISC-V Toolchain | Cross-compilation |
| RVV | Vector acceleration support |
